# 客户端迁移成本实测

2026-09-13，在同一台 macOS arm64、Chrome 153.0.8010.36 上，以 all-api 教程比较迁移前提交 `e55c4fec798528e795edc8f7a6ba9d83c8eac8ee` 与当前实现。以下是一次本机 localhost 测量，不代表移动设备、网络下载耗时或服务器容量。

| 项目                       |     预渲染 SVG |       客户端准备 |
| -------------------------- | -------------: | ---------------: |
| 发布 JSON（UTF-8）         |    1,395,319 B |          8,126 B |
| JSON gzip                  |       99,481 B |          1,807 B |
| 页面请求响应体合计         |   24,730,037 B |      5,932,105 B |
| 响应体分别 gzip 的合计     |   15,321,218 B |      1,694,822 B |
| 冷启动至 ready             |          93 ms |         4,147 ms |
| 再次准备（无素材持久缓存） |         不适用 |         4,119 ms |
| 播放主线程任务时间 / 帧    |        2.96 ms |          1.78 ms |
| 精确跳转平均 / P95         | 1.77 / 2.30 ms | 16.50 / 16.80 ms |
| GC 后 JS heap              |    3,434,236 B |      3,747,356 B |
| 全教程导出耗时             |        469.2 s |           68.9 s |
| 导出 Node 峰值 RSS         |  751,288,320 B |    252,739,584 B |

JSON 原始大小减少约 99.4%，gzip 减少约 98.2%。客户端增加了 Blockly、VM 数据目录桥接和原生外壳模板：主要脚本约 5.25 MB 原始大小，当前语言/主题的外壳约 366 KB（gzip 86 KB）。模板由多个教程共享；每次只加载当前组合。

下载行比较的是产品默认字体行为：旧版必须下载这次基线使用的 23,278,008 B 字体文件，新版使用系统字体。扣除旧字体后，旧版页面资源约 1.45 MB，低于新版约 5.93 MB；因此不能把默认字体下载的节省归因于渲染依赖变小。合计统计各响应的解压后内容，重复请求会重复计入，不等同于浏览器缓存后的实际网络传输量；gzip 行是离线估算，并非本机服务器启用了 gzip。需要网络性能结论时还应在目标 CDN 和设备测量。

播放主线程指标使用 CDP TaskDuration，在教程第 10 秒开始采样约 1.5 秒、90 帧。跳转指标语义不同：新版等待页面绘制和视频帧完成，旧版只是同步替换 SVG，因此新版约一帧的等待不代表 CPU 渲染慢了十倍。JS heap 不包含完整浏览器进程内存，iframe 销毁也不保证所有代码立即回收。

导出均为 1280×720、30 fps、805 帧，教程长度 26.81765 秒，编码长度 26.83333 秒，显式使用同一 Arial Unicode 字体，SHA-256 为 `876af2cd4854644e7f3e7feb2f688997fdb3343c6df6693611209c9dfb47ccec`。新版 68.9 秒包含约 4.9 秒准备。RSS 只统计 Node，不包含 Chrome、FFmpeg 子进程，因此不能据此宣称整个导出任务内存降低同样比例。独立舞台测试还验证了裁剪片段的已知颜色帧、尺寸、帧数和无音轨。

## 复测

保留旧版生成的 `artifacts/all-api/scene.json` 作为历史输入，构建新版 runtime 后执行：

```sh
node scripts/migration-cost.mjs /absolute/path/font.ttf
# 仅重新测播放，保留已有全教程导出结果：
node scripts/migration-cost.mjs /absolute/path/font.ttf --playback-only
```

原始结果写入 `artifacts/migration/cost.json`；视频为同目录的 `old-all-api.mp4` 和 `current-all-api.mp4`。旧输入不作为当前 playground 入口。外壳、字体隔离及缓存内容的小幅收尾修改可能使资源字节数略有变化，表格保留本次测量原值。
