# P3 浏览器有限交互与视觉变体

P3 提供工作区平移／缩放、浅色与深色、中英文素材和保留时间的选项切换。播放器消费静态 SVG，不创建 Blockly workspace，观众不能改变积木或项目。

## 使用

```sh
pnpm p3
pnpm preview
```

打开 playground 默认的 P3 示例。拖动／滚轮／触摸板双轴平移，Shift+纵向滚轮横移，Control+滚轮（含触摸板捏合产生的 ctrlKey 事件）以鼠标位置为中心缩放。使用 Blockly 的 1.2 倍步进、每 50 px 一步及行模式 15 倍系数，绝对积木比例限制在 0.3–3；触摸拖动可平移。聚焦画面后方向键平移，`0` 或工作区内“恢复视角”按钮复位；另两个按钮分别放大、缩小，支持键盘激活。网格随视角平移／缩放；平移／缩放自动暂停，继续播放和跳转恢复教程视角。工具箱与角色区不响应观众编辑。

逻辑画布仍是 1280×720；容器按比例缩放，不改变教程布局。375、800、1280 px 容器均可播放，窄屏控制栏换行。手机画面整体缩小，需要时可放大工作区；本阶段不增加移动端 IDE 布局或双指缩放。

## API 与资源

`TutorialSpec.defaults` 支持 `theme: 'light' | 'dark'` 和 `locale: 'zh-CN' | 'en'`。`createAdapter({ project, locale, theme })` 准备相应资源；CLI 自动传入教程 defaults，编译器拒绝与 adapter 不一致的配置。

英文通过固定 Blockly 的 `ScratchMsgs.setLocale('en')` 重新提取完整目录、字段菜单、文本、几何和锚点，不在播放器翻译积木 SVG。菜单、标签页、搜索框和顶栏按钮在字体加载后实测对应语言文字宽度，再按固定 GUI 的内边距与图标间距生成布局；英文不再复用中文坐标或缩小字号。教程文本、角色名和变量名保持作者原文。语言不同可能产生不同默认文本和目录键，作者应使用相应目录中的完整键；本阶段不引入别名映射。

浅色／深色共用积木几何和原始积木配色，通过 `manifest.colorTheme` 选择受控外壳、菜单、标注与 IME 配色；`manifest.theme` 仍保存素材 CSS。深色表面与文字颜色参考固定 GUI 的 `src/lib/themes/gui/dark.js`，红色品牌色保留。两个渲染后端共用外观处理，不使用整体反色滤镜。

```ts
const player = mountPlayer(host, compiled, {
  async loadVariant({ locale, theme }, signal) {
    const response = await fetch(`/scenes/tutorial.${locale}.json`, { signal });
    if (!response.ok) throw Error('Variant unavailable');
    const scene = await response.json();
    return { ...scene, manifest: { ...scene.manifest, colorTheme: theme } };
  },
});
await player.setOptions({ locale: 'en', theme: 'dark' });
player.resetView();
player.dispose();
```

语言加载器必须返回同一教程的对应编译资源；播放器检查资源完整性、语言、主题、项目、画布与字体一致。主题切换不加载素材，语言切换支持 AbortSignal、最新请求优先、加载提示和失败后保留旧画面。切换时暂停并保留秒数，成功后恢复教程视角；如果新变体较短则限制到其结尾，不按步骤重新映射时间。失败通过 promise 拒绝并显示状态。未配置加载器时跨语言切换明确报错。

`player.view` 返回独立的 `{ x, y, zoom }`，不回写场景。`frameSvg(time, compiled, namespace, view)` 可显式渲染相同覆盖；普通视频导出始终使用教程视角。输入框、IME、菜单、标注、静止积木和工作区内非拖动状态的教程鼠标同步变换。拖动中的教程鼠标固定在屏幕坐标，积木围绕抓取点缩放，忽略观众平移，裁剪保持在固定工作区。

销毁会取消 RAF 和未完成的变体请求，移除监听器、SVG 图层和场景／加载器引用。销毁后重复调用控制方法不会恢复画面；不保留语言资源缓存。

## 验收

```sh
pnpm test
pnpm test:integration
```

`tests/integration/p3.test.mjs` 重新生成默认 all-api 教程的中英文资源，覆盖运行中交互暂停、坐标变换、恢复视角、保留时间、响应式容器、异步请求竞争、失败恢复、销毁后迟到结果及源场景不变。四组中英文／浅深色浏览器与 resvg 关键帧要求平均通道误差低于 3、差异像素比例低于 2.5%（通道差 >32）。

结果位于 `artifacts/p3/`，包含两份场景、交互截图、三种容器截图和四组双端 PNG。默认示例中英文均为 240 份资源、26.817654550104717 秒。P3 验证关键帧与交互；长视频、内存预算和缓存性能留在 P4。

2026-09-13 验收：TypeScript 构建、22 项单元测试、9 项集成测试、格式检查和 `git diff --check` 通过。四组双端关键帧符合上述阈值，已检查深色英文及窄屏截图；默认 playground 中英文场景已重新生成。当前环境 pnpm 的固定版本签名校验因 registry fetch 失败而无法启动，验证使用已安装的 TypeScript、Prettier 和 Node 测试入口完成。
