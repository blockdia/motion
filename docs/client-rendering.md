# 客户端准备与原生外壳

教程发布为版本 2 的语义 JSON，客户端根据本机字体准备积木素材和时间线。准备完销毁独立 iframe 中的 Blockly 工作区及必要的 VM 数据模型，正式播放由持久 HTML/SVG 节点完成。没有 Scratch 项目执行、舞台 VM 或完整 GUI 应用运行。

## 外壳来源

`scripts/build-shell.mjs` 启动固定 GUI 构建，提取真实顶栏、标签、属性、角色、舞台控件、背包和分类区域的 DOM/CSS，移除应用脚本与项目渲染内容，并将图片与 CSS 图片依赖嵌入模板。保存中英文、浅深主题的四份共享外壳模板及原生布局测量。CSS 声明从原始样式文本经 PostCSS 处理并保留顺序，不使用 CSSOM `cssText` 重新序列化：后者在 Chrome 中可能将变量边框颜色与后续单边 shorthand 的组合写成空值。

原生 flex 布局在客户端继续生效；固定逻辑画布为 1280×720，宿主容器只整体缩放。模板样式按播放器实例隔离，原生 rem 转为固定画布像素，避免宿主页面的根字号改变教程。字体由播放器显式继承，默认使用客户端的 Helvetica Neue、Helvetica、Arial、sans-serif 字体栈。

运行时复用原生结构并更新角色属性、卡片选中状态和分类状态。积木、拖拽预览使用 SVG，菜单、模拟输入框、IME 和标注使用受控 HTML。项目上下文只有造型名称，没有图像内容，因此角色缩略图区保留空白，不冒用默认猫咪图片。

## 构建与数据流

1. `bundleTutorial` / `motion compile` 校验 JSON 结构、规范化操作，预先生成与字体无关的中文输入序列。发布资源不包含工具箱、积木状态 SVG 或测量结果。
2. 浏览器加载对应原生外壳和字体，测量布局区域，再创建同源临时 iframe。iframe 使用固定版本 Blockly 与原有目录桥接生成完整目录和教程所需状态。
3. 语义编译器解析字段和连接锚点，生成运行时 `CompiledScene`。同一准备会话内复用按内容寻址的素材，首轮不增加持久素材缓存。
4. 准备完成后移除 iframe。播放器按时间求值，更新节点变换和受控 DOM；素材变化时才替换对应积木 SVG 内容。嵌入的 SVG 使用块级布局，避免行内基线引入坐标偏移；鼠标独立位于原生壳层之上。
5. 字体、语言或主题切换重新准备；最新请求优先，失败保留旧画面。准备失败、取消及播放器卸载均释放临时环境。浏览器自行决定何时回收已下载 JS。

运行时生成目录可直接静态托管，包含模块、Blockly、目录桥接、媒体图标、外壳模板和第三方许可。正式播放不访问源码 checkout、`.cache` 或 Node API。完整 GUI 仅用于构建外壳模板。`runtime:build` 校验固定 Blockly 与目录构建摘要，提取器变更后自动重建外壳。

## 舞台与导出

舞台使用静音视频。精确跳转会等待视频解码及页面绘制；普通播放以教程时钟为主，进行媒体漂移校正，缓冲期间冻结教程进度。片段外显示空舞台，不保留上一段末帧。

视频导出使用同一准备器和确定性时间快照，默认缓存真实 UI 图层截图与 SVG 栅格素材，再逐帧图片合成；`backend: 'screenshot'` 保留逐帧 `renderAt` 截图参考。两种方式均不采用实时录屏，详见 [导出后端对比](video-export.md)。导出要求显式字体文件，报告浏览器版本、字体摘要、帧率、画布、耗时与 Node RSS。网页系统字体与导出字体可能不同，不保证跨系统像素相同。

## 验证与限制

测试保留现有积木操作、目录键、项目作用域、并发冲突及真实 Blockly 合法性检查，并覆盖多实例、取消、字体和主题切换、窄屏、舞台裁剪与导出。原生外壳的关键区域在四种语言/主题组合下与真实编辑器的几何和背景比较。

当前不实现观众自由编辑、造型编辑器、实时执行项目、移动端 IDE 重排或音轨混合。覆盖更多界面功能时，应继续扩展原生模板与受控状态，而不是恢复手写近似外壳。
